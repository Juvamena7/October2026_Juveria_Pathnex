# Matrix Builds: A matrix build in Jenkins allows us to execute the same pipeline stages across multiple combinations of configuration values. We define axes and their values, such as Java versions or operating systems. 

# Jenkins generates a separate matrix cell for each combination and runs the specified stages for each cell. This helps us test application compatibility across different environments without maintaining multiple duplicated jobs.

## 🔹 Jenkins Pipeline — Matrix Build
You will learn how to **run the same build on multiple environments**

pipeline {
    agent any 
    environment {
        INSTITUTE_NAME  = "pathnex"
    }
    matrix {
        axes {
            axis {
                name 'JAVA_VERSION'
                values '8', '11', '17'
            }
        }
        stages {
            stage('Build') {
                steps {
                    sh "echo Building with Java $JAVA_VERSION"
                }
            }
        }
    }
}
